# FinalPaint
My take on Microsoft Paint made during a college class. Done in Java IntelliJ on Oracle openJDK 20.0.2
See Paint_Version_History.txt for full features list and timeline of changes.
Noteworthy Features:
Full drawing capabilities with different markers, colors, shapes, and more.
Ability to save and load drawings from local storage including autosaving.
Undo and redo functions as well as drawing across tabs.
